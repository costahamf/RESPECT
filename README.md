## Инструкция по Yandex Maps API

1. Перейти на https://developer.tech.yandex.ru/services/
2. Создать ключ для JavaScript API и HTTP Геокодера
3. Вставить ключ в переменную `YANDEX_MAPS_API_KEY` в коде (`index.html`)
4. Ограничения: бесплатно до 25 000 запросов в сутки

## Запуск

Откройте `index.html` в браузере или загрузите файл на любой статический хостинг.
